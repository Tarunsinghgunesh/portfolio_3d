- **Interactive 3D Engine**: Canvas API, Custom Particle Systems, Dynamic Matrix Lighting

- **Backend & Realtime**: Firebase Auth, Supabase Postgres & Realtime WebSockets
- **Native Android**: Android Studio, WebView Bridges, Razorpay Payment Gateway, EmailJS Integration
